InventoryMonitorApp

InventoryMonitorApp is a mobile-based system designed to help businesses monitor and manage their inventory in real time. It streamlines operations, reduces errors, and improves efficiency for small and medium enterprises.

Features

  • Real-time stock tracking
  • Dashboard for quick insights
  • Mobile-friendly interface
  • Secure authentication with Google sign-in

About

This app was developed as part of a thesis project using Design Thinking and the Technology Adoption Model (TAM). It leverages Supabase for backend services and Expo/React Native for the mobile prototype.
